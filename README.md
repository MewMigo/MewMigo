# MewMigo — Cat Affiliate Website Starter

This is a static, mobile-friendly affiliate-site starter.

## Included
- Home page
- Shop with 30 starter products
- Category filtering
- Product search
- 10 guide/article pages
- Product finder quiz
- About page
- Affiliate disclosure page
- Responsive CSS

## Before publishing
1. Join the affiliate programs you qualify for.
2. Replace the `url:"#"` values in `products.js` with your approved affiliate URLs.
3. Replace placeholder product descriptions with verified information.
4. Add your own product images only when you have permission/licensing or are using an affiliate program's permitted image tools.
5. Review each affiliate program's terms, required disclosures, and rules for price/product data.
6. Add your final site name, contact information, privacy policy, and any other pages required for your operation.

## GitHub Pages
Create a GitHub repository, upload all files in this folder to the repository root, then enable GitHub Pages from the repository settings. The site is static and does not require a server or database.

- `images/mewmigo-hero.png` — clean hero lifestyle image. Website text and buttons remain real HTML elements.
